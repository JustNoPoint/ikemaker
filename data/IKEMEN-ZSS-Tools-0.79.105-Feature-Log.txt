IKEMaker 0.79.105

Text editor toolbar cohesion

- Adds one nested IKEMaker right-click menu with Navigate, Edit & Insert, Preview, Safety, specialty tools, and Project & Run categories.
- Replaces the previous non-ZSS wall of direct context-menu commands.
- Caps supported text-editor title bars at four context-aware actions: Go to Line, Comment/Uncomment, one file-specific primary tool, and searchable Actions.
- Adds an optional Text Toolbar Companion with compact dropdowns, search, favorites, and active-editor following.
- Keeps the companion closed by default and never opens it merely because an editor gained focus.
- Classifies character, stage, screenpack, and roster DEF files so irrelevant tools remain hidden.
- Supports ZSS, CNS/ST, CMD/INP/JNP/DAT, AIR, DEF, Lua, and explicitly opted-in code TXT files while leaving ordinary TXT files untouched.
- Routes every toolbar action to its existing command owner, preserving source validation, confirmation, backups, history, and Undo behavior.
- Changes automatic AIR visual-workspace opening to off by default.
- Adds portable browser-host Actions access without claiming the desktop companion panel.

Verification

- New developer design and safety sign-off completed before implementation.
- All 409 automated test files pass.
