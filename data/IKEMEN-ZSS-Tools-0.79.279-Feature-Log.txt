IKEMaker 0.79.279

Cold-start Text Editor restoration

- Fixed Text Editor toolbar and icon navigation after closing every tab/window and reloading IKEMaker.
- Restored SFF, AIR, and SND viewers are now recognized from their exact live VS Code tab even before IKEMaker's in-memory viewer tracking has been rebuilt.
- A clean viewer no longer blocks the first text editor opening merely because no source tab is already visible.
- An empty workspace now creates the compact Code Navigation header and native text work area before opening the exact requested source.
- Genuine busy, pending, or unapplied viewer edits still stop the transition so work is not discarded.
- Added reload, empty-workspace, restored-viewer, and busy-restored-viewer regression coverage.
