IKEMaker 0.79.403 - template-image removal coverage preview

Right-clicking an imported image on the template canvas now reports whether it
is safe to remove before deletion is requested. Safe images state that every
retained color also appears in another template image and label the action
"Remove from Template (safe)."

Images that uniquely represent retained colors show the exact unique count and
the count shared with other template images, making it clear that removal will
open the existing safety warning. The menu reads the retained intake coverage;
it does not rescan or decode image files when opened. Removing a canvas layer
continues to keep the imported source image.

This build also includes connected separator chains and their bounded local
Undo/Redo history: Ctrl+Z undoes, while Ctrl+Y and Ctrl+Shift+Z redo an entire
finished chain in one step.

Regression coverage verifies safe/warning menu text, retained-coverage reuse,
connected drawing, atomic chain history, keyboard shortcuts, source retention,
and existing protected-removal behavior.
