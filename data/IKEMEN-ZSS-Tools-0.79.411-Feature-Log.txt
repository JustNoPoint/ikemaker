IKEMaker 0.79.411

Responsive color-filter ordering and cached coverage

- Places selected-color sprite ordering directly in the swatch right-click menu: greatest pixel use first or least nonzero pixel use first.
- Renames the original command to Sort color table by total pixel count so it is no longer confused with sprite-result ordering.
- Selecting an order from the swatch menu also selects that swatch and returns to the first matching-results page.
- Computes template unique-color coverage in linear time and retains it by exact image layout, cleanup masks, ignored colors, and transparent color instead of rebuilding it for every filter.
- Splits adjacent-page thumbnail preloading into small background batches. A new color choice cancels stale preloading and runs before more background work.
- Verified with the saved 1,502-image vsav2000 session: after the contact page is prepared, a new 48-thumbnail color filter completes in roughly 436 ms in the host benchmark.
