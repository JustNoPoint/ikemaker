IKEMaker 0.79.399 - stop Palette Workshop animation-preview feedback

AIR animation preview validation is read-only. It no longer refreshes and
notifies the entire palette session, which triggered another live rendering
and another animation request indefinitely. Identical client preview requests
are cached by animation, palette identity and archive evidence; Replay forces
a fresh request. Cached frames remain available after unrelated rerenders.

Viewport restoration is bounded to host updates and never issues a redundant
same-position scrollTo, which can interrupt native browser scrolling. User
input remains the final authority. No temporary diagnostic logging is shipped.

Regression coverage includes read-only host preview validation, unchanged live
rerenders, explicit Replay, changed archive evidence, deep bank replacement,
rapid updates, native paging, idle layout changes and anchor expiration.
