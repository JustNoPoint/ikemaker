IKEMEN ZSS Tools 0.79.270

Reliable Text Editor Handoffs

- Fixed loose-file startup so IKEMaker no longer attempts workspace-only display-setting writes when no folder or workspace is open.
- Text Editor toolbar and icon routes now always fall back to the exact native source file when Code Navigation is unavailable, still starting, or refuses a mixed viewer group.
- The exact source is explicitly refocused after optional Code Navigation attachment so a browser or header cannot cover it.
- AIR pencil and source buttons now allow floating AIR browsers to return to the main window before opening text.
- AIR browser reveal is allowed to settle before live topology checks, removing the hidden-browser activation race.
- Once an AIR source opens, optional header or topology degradation leaves the source visible with its native return controls instead of re-revealing the browser over it.
- SFF toolbar navigation failures now produce a visible error instead of disappearing inside the webview message handler.
- Added regression coverage for loose-file startup, rejected and unavailable companion commands, AIR header degradation, floating-browser restoration, and final source focus.
