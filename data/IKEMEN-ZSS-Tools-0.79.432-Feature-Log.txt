IKEMaker 0.79.432

Visible true-color SFF intake and exact writer routing

- The compact Add Sprites popup keeps a visible Image Intake bar while scrolling and resets retained scroll position whenever it opens.
- The full SFF Creator Sources section now has an explicit Add True Color PNG Files action for complete 8-bit RGB24 and RGBA32 PNG sources.
- True-color intake validates the entire selection before changing the retained draft and rejects indexed or unsupported PNGs atomically.
- The shared writer selector remains authoritative: IKEMaker uses the native PNG24/PNG32 route and SprMake2 uses its existing true-color route without silently changing the selection.
- Selecting IKEMaker now invokes a dedicated native SFF v2.1 single-writer test build. It no longer accidentally dispatches the two-writer SprMake2 comparison.
- Both-writer comparison alone remains disabled for true-color until mixed-output comparison is supported; the UI explains that narrow limitation.
- Compact and full Creator screens display writer-specific true-color guidance before submission.
