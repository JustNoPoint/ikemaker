IKEMaker 0.79.170

AIR browser source escape and detached-window safety
- AIR source navigation distinguishes IKEMaker-owned floating browsers from windows detached through VS Code.
- Owned floating browsers return to the main workbench before the exact source editor opens.
- Manually detached browsers switch focus to the main workbench without merging unrelated auxiliary editor groups, changing always-on-top, or emitting false window state.
- Failed focus or restoration keeps the source closed and leaves the exact AIR browser available.

Escape controls and lifecycle
- Routed sources retain exact-line Return to AIR and Close Source controls through CodeLens, editor title, status bar, and the text header when present.
- Dirty close cancellation stays on the source; normal tab and window close do not reopen either surface.
- Existing provisional-handoff rollback prevents a delayed failed route from erasing a newer successful route.
