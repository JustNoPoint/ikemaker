IKEMaker 0.79.262

Palette Workshop consolidation and two-bank editor repair

- Removed the duplicate oversized embedded-palette index from the persistent Palette Workshop layout.
- Bank A is now the selectable source palette and Bank B is the editable/reorder target.
- Preserved click, Shift-range, Ctrl-toggle, drag/copy, and in-bank reorder behavior for palette colors.
- Fixed the hue/saturation wheel rendering black when a dark or black color was selected.
- Picking a hue from black now starts with visible brightness while the Value control remains available for exact adjustment.
- Made the two-bank editor stack earlier and prevent control overlap in narrow windows.
- Separated the SFF Palette Browser from the canonical Palette Workshop: browsing and previews remain in the browser, while editing opens/focuses the single current workshop.
- Canonical workshop launches now retain the exact SFF, physical sprite, physical palette, origin, return context, and requested section.
- Updated the Palette Workshop viewer-browser route so it no longer opens the retired embedded workshop.
