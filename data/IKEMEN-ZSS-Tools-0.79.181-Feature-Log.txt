IKEMaker 0.79.181

Palette Workshop palette-image registration
- Standard Batch Tools now has a concise Palette images shortcut into Advanced > Sync / Remap / Repair > Sync Images.
- Register indexed PNGs or manage selected saved registrations in one compact, one-column workflow that remains usable in narrow browser docks.
- Exact palette matches may be preselected; ambiguous matches require an explicit embedded palette choice. Existing registrations can be enabled, disabled, removed, or relinked.
- Filename coordinates are suggestions only. File paths, template identity, registration identity, palette identity, and relink targets remain host-authoritative behind opaque browser IDs.
- Review and Save registrations change metadata only. The active SFF and PNG files stay unchanged.
- Post-write verification failures now truthfully remain visible as a persistent Reload required warning; discarding another draft cannot erase that warning.

- Exact registry/template/PNG evidence, stale/replay/revoke behavior, committed-but-unverified failures, ambiguous enable/relink, narrow accessibility, workflow reachability, and direct-write audits pass.
