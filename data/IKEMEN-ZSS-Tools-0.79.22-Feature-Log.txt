IKEMaker 0.79.22 — Authoring Catalog foundation

- Added one shared Authoring Catalog identity model for ZSS structures, universal recipes, recipe sections, and bundled example-pack foundations.
- Added Authoring Quick Access at the top of the State Controllers sidebar.
- Sidebar quick access keeps Favorites and Recent separate and links to the complete authoring pages instead of listing the full catalog.
- Added a Recipe Library with project-neutral Basic Normal, Basic Special, Helper Projectile, and Map Cleanup recipes split into independently insertable sections.
- Added Project Symbols & Contracts as the future combined home for maps, constants, functions, commands, state ranges, helpers, contracts, uses, and validation. Existing Project Maps remains linked while that index is expanded.
- Added Example Templates foundations for SF6, Darkstalkers, Darkstalkers 4, and Hyper Dragon Ball Z. Entries are honestly marked as reference foundations until attribution, licensing, manifests, and capability validation are completed.
- Added synchronized catalog favorites. Favoriting on a library page exposes the same stable item in the controller sidebar.
- Added local recent insertion tracking without converting recents into favorites.
- Added catalog search by label, description/intent, family, source, compatibility, and stable ID.
- Logged the complete reviewed recipe, example-pack, extension-package, website, in-app Community Library, author/reputation, rating/review/comment, and anti-spam direction. Community delivery remains after Phase 1.

Safety boundaries:
- Universal recipes contain no SF6/project maps or author-specific requirements.
- Template examples are not labeled as IKEMEN rules.
- This slice performs only explicit single-section insertion into an open ZSS/CNS editor.
- Multi-file recipes, dependency imports, project activation, and community installation remain unavailable until preview, transaction, validation, and rollback requirements are implemented.
