IKEMaker 0.79.409

Faster Palette Workshop color filters

- Renders each filtered thumbnail directly from its source pixels at preview size instead of first copying and processing the entire full-resolution sprite.
- Applies cleanup masks, ignored colors, and the darken/lighten focus effect in the same preview pass.
- Keeps the existing completed-preview cache, so revisiting a color and focus mode remains immediate.
- Adds explicit Greatest first and Least first pixel-count ordering for sprites containing the selected color. Least first is useful for finding small or easily missed uses; zero-match sprites remain excluded.
- Verified against the saved 1,502-image vsav2000 session: the 48 visible filtered thumbnails reduced from roughly 729 ms to 336 ms on the same machine, about 54% faster.
- Adds pixel-exact regression coverage comparing the optimized preview with the prior rendering pipeline.
