IKEMaker 0.79.427

Release-candidate palette template indexing

- A completed palette table now writes a genuine indexed PNG rather than an RGBA PNG carrying palette metadata only.
- The assigned transparent/background color is protected at index 0 in the flattened template.
- The paired IKEMaker setup records indexed-output, index-plane, and palette hashes for later verification.
- Answering No to "finished updating the palette table" does not export or reset anything. It opens the retained CS & Palette Index Editor instead.
- Existing completed color assignments keep their planned indices. Newly assigned colors use available nonzero cells without silently renumbering completed colors.
- The unfinished-table handoff remains isolated from any open character or SFF until the user explicitly chooses an add/apply route.
- Truecolor sources remain exact RGBA evidence while indices are being built; no predetermined source index is required.
- Custom-background and truecolor-alpha blends must be reviewed in the index editor. Final export will not silently invent unlisted palette colors.
- Added regression coverage for decoded PNG color type, exact index 0, retained partial assignments, sidecar authority, and unsafe alpha-blend rejection.
