IKEMaker 0.79.23 — First complete project recipe model

- Added the current SF6 Standing Light Punch (sLP) as the first project recipe.
- The recipe treats JNP_SF6_StandingLightPunch as the primary authored move unit. State 200 is its small engine-facing shell; the shared JNP_SF6_LightPunch function remains reusable family infrastructure.
- Captured eight named parts: command route, State 200 and call site, configured wrapper, move constants, shared SF6 light-punch implementation, shared State -4 lifecycle, shared cancel routes, and AIR/SND ownership.
- Shows the configured state, animation, command, complete current Ryu constant family, and primary move function.
- Lists its SF6 dependencies: shared light-normal/configuration maps, combo scaling, cancel contracts, attack metadata, reaction regions, armor, Drive, UI events, corner recoil, animation 200, and the owned voice/FX sounds.
- Move-local code sections can be inserted individually into the correct file type.
- Shared infrastructure is reference-only so IKEMaker does not duplicate hundreds of shared lines into every authored normal.
- Insertion refuses a section when the active editor is the wrong file type.

No whole-move or multi-file insertion is enabled yet. That remains gated on exact destination planning, duplicate/dependency checks, transactional edits, validation, and unified undo.
