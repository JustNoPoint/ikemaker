# IKEMaker credits

IKEMaker draws on a long history of authors sharing tools, techniques, and feedback with the fighting-game community. Thank you for helping people make characters and games.

## Project

**JustNoPoint (JNP)** leads IKEMaker's design and development, drawing on years of character work for Hyper Dragon Ball Z. OpenAI Codex has assisted with implementation, testing, and review since early development. [IKEMaker project](https://github.com/JustNoPoint/ikemaker)

## Tools and inspiration

- **Elecbyte** created M.U.G.E.N. IKEMaker uses Elecbyte's SprMaker2, SndMaker, and SFF2PNG tools. [M.U.G.E.N documentation](https://www.elecbyte.com/mugendocs-11b1/mugen.html)
- **The IKEMEN GO contributors** develop the engine and maintain the wiki used throughout IKEMaker. [IKEMEN GO project](https://github.com/ikemen-engine/Ikemen-GO)
- **VirtuallTek Game Studio** developed Fighter Factory. Its sprite, palette, and animation editing workflows informed IKEMaker's viewer design. [Fighter Factory](https://virtualltek.com/fighter-factory/)
- **PotS** developed IKEMEN Media Editor and maintains the merged engine documentation. [IKEMEN Media Editor](https://github.com/potsmugen/ikemen-media-editor) · [Merged documentation](https://potsmugen.github.io/ikemen-merged-docs/)
- **Tunglashor** developed VSelect, the inspiration for IKEMaker's visual roster editor. [VSelect](https://vselect.neocities.org/)
- **@stgfullpower** shared the orbit-authoring demonstration that inspired Orbit / Trajectory Assist. [Watch the demonstration](https://x.com/stgfullpower/status/2109666938167431401)

## Community feedback

- **Junny** reported unwanted backups and tab movement issues, and suggested publishing the source directly in the repository.
- **Rakíel** reported excessive Lua diagnostics and warnings involving P2 references.
- **KOFHERO77** tested palette insertion, reported a build action that appeared to do nothing, and suggested palette list removal and index cleanup.
- **Charion** helped identify how difficult the Command Editor was to find.
- **Pedro Andrade** asked for a guide to help users navigate the features.
- **Balthazar** suggested using a character's last chosen palette for their portrait on the main menu.
- **PotS** shared feedback on maps and IKEMEN command input syntax.

If we missed a contribution or you would like your credit corrected, please tell JustNoPoint or use the [project issue tracker](https://github.com/JustNoPoint/ikemaker/issues).
