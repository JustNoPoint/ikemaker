IKEMaker 0.79.175

Saved color rules in SFF Creator
- The final Conflict / Final Review step now contains one collapsed Saved color rules card.
- Review shows exact reusable color decisions with source and destination swatches, destination palette index, and affected image and pixel counts.
- Apply one, Accept all exact, Ignore this intake, and Open in Palette Workshop are explicit choices. A saved rule is never applied merely because it matches.
- Stale and conflicting rules remain visible with concrete reasons and accurate bounded omission counts.

Palette Workshop round trip
- Open in Palette Workshop uses the canonical Workshop instead of creating a duplicate editor.
- Workshop open and return routes are opaque, single-use, and revalidated immediately before the next action.
- A reviewed Workshop return updates only the retained SFF Creator resolution draft and survives a safe reopen.
- Changed targets, sources, decoded pixels, palettes, rules, profiles, drafts, disposed panels, and replayed routes fail closed.

Exact evidence and safety
- Review authority binds the canonical target identity and target bytes, exact physical master palette and colors, ordered source hashes and decoded-pixel hashes, scan hash, rule-registry revision and bytes, conversion profile, alpha policy, Creator generation, and draft revision.
- Registry files and imports are bounded before JSON parsing. In-memory rules, nested source references, scan issues, occurrences, resolution patches, strings, pixels, files, and aggregate evidence are bounded before recursive hashing.
- Accepted saved-rule provenance is retained in the resolved-image manifest and freshly revalidated before package or candidate construction.
- The workflow never automatically changes source images, the active SFF, or saved replacement rules.

Accessibility and verification
- The card is compact and collapsed by default, uses native buttons and live status, exposes color swatches as labelled images, and becomes one vertical action column in narrow docked windows without page-level horizontal scrolling.
- New Dev reviewed the design before implementation and rejected intermediate passes until target identity, decoded pixels, single-use handoffs, aggregate bounds, post-await revalidation, bounded reads, stale details, exact omitted counts, and the Workshop return path were closed.
- All 147 selected Palette and SFF Creator suites pass, including the long-running operation-vault, lifecycle replay, recovery, result classification, persistence, narrow-layout, accessibility, and direct authority regressions.
