Manual limits for this release:
- The helper tree is a static source graph, not a live runtime instance graph.
- Maps have full contract generation. Vars, states, animation, spatial mutation, resources,
  and combat mutation route to their specialized editors and still require author review.
- Dynamic helper IDs, computed StateDef targets, and arbitrary nested code blocks may need
  manual confirmation when static detection cannot prove their relationship.
