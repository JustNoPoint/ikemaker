IKEMaker 0.79.240
=================

Lua authored-function assistance
--------------------------------
- Adds native completion, hover, and Signature Help for authored Lua functions.
- Recognizes top-level local/global declarations, table and colon methods,
  assignment-form functions, and variable arguments.
- Uses exact authored parameter names and adjacent EmmyLua-style documentation.
- Admits direct required-module members only when one exact same-folder Lua
  module resolves and explicitly returns their owner.
- Never executes Lua or invents parameter types, defaults, or return behavior.
- Applies bounded source/module budgets and revalidates source and dependency
  authority before publishing asynchronous help.

Lua tabs in Code Navigation
---------------------------
- Lua files now show a visible Lua type label in the TXT/Code Navigation header.
- The label is also included in accessible tab names and remains correct when a
  generic filename is explicitly opened with the Lua editor language.

Review and verification
-----------------------
- New Dev reviewed and expanded the lexical-scope, module-ownership, stale-data,
  and header-label behavior.
- Eleven focused coding tests pass. The unrelated SFF suite was not rerun.
