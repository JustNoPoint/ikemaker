Palette Workshop Bank B index policy:

- Bank B now has independent Retain color values and Offset colors checkboxes directly below the bank.
- Retain color values keeps indexed sprite pixels visually connected to their original colors while Bank B is rearranged. The live Preview B remaps display and editing indexes without altering sprite data.
- Offset colors on performs stable insertion and shifts the surrounding Bank B indexes. Offset colors off swaps or rotates only the selected colors and destination indexes, leaving unrelated indexes unchanged.
- Shift and Ctrl multi-selection preserve exact index identity, including duplicate RGBA colors. Transparent index 0 remains protected.
- Bank B copy, rearrange, and clone changes have local undo/redo. Clone A to B resets retained index connections to identity.
- Adoption is blocked while retained index connections are non-identity, preventing an unsafe one-sprite rewrite; a reviewed all-attached-sprites reindex is required before adoption.
- Bank B state is tied to exact SFF filename, byte hash, byte length, and physical palette. Reloading changed archive bytes clears stale colors, mapping, and history while changing sprites within the same archive preserves the draft.

Focused dual-bank, sprite-editor, Palette Workspace, syntax, permutation/property, and stale-archive identity checks pass. New Dev reviewed the index movement and preview mapping policy.
