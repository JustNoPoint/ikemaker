IKEMaker 0.79.173

AIR source escape and universal header
- Opening source from AIR Actions Browser now transitions through the same protected Code Navigation text-header contract used by other IKEMaker text editors.
- Exact routed AIR, ZSS, and CNS sources expose persistent, keyboard-focusable Return to AIR and Close Source controls in that header.
- The compact control row remains reachable in narrow docked or auxiliary layouts without horizontal page scrolling.

Retained text workspace and exact ownership
- AIR source navigation augments the retained Character Essentials tab set instead of replacing it with one source.
- The exact routed source becomes the selected tab while prior connected files remain available.
- Shared and template sources remain classified relative to the AIR character owner; they cannot silently become a new character workspace.

Fail-closed lifecycle
- The source handoff is registered before native rendering and the universal header is then required.
- If header attachment fails, the exact retained AIR Actions Browser is immediately revealed instead of leaving a raw source editor in front.
- Return reuses the originating browser and its saved action, frame, collision, filter, and view state; it does not create another browser or window.
- Normal source/window close remains native. Dirty close cancellation does not falsely return or reopen a surface.

Keyboard and fallback access
- Alt+Left returns an exact routed source to its originating AIR Actions Browser.
- Existing CodeLens, editor-title, and status-bar actions remain redundant exact-source fallbacks.
- Disabling CodeLens no longer blocks source navigation when the required universal header attaches successfully.

Verification
- New Dev reproduced and blocked the raw-editor behavior before implementation, then identified the CodeLens, retained-tab, and shared-owner edge cases during post-review.
- Focused AIR source-escape, collision-context, collision-inspection, hit-region, reference-authority, text-companion, platform-capability, and toolbar-contract tests pass.
