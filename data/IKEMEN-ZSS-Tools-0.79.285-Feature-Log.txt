IKEMaker 0.79.285

mainThreadWebview- prefix when matching IKEMaker viewer tabs. Clean viewers
can now transition to the focused native text editor with Code Navigation
above it instead of being mistaken for unrelated tabs.

longer automatically opens a side-by-side source editor.

suites pass, including host-prefixed tabs and never-dismissed notifications.
