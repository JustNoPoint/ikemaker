IKEMaker 0.79.311

Template Creator blocking shared-color warning

- Selecting a region defaults to removing every exact color found inside it.
- If none of those colors occur outside the region, the removal can proceed
  without an additional shared-color decision.
- If any color is also used outside the selection, IKEMaker stops and displays
  one warning for the whole operation.
- The warning requires one explicit choice:
  - Remove only the selected region, preserving matching pixels elsewhere.
  - Remove all instances of every selected color from all imported images.
- The host recomputes the exact reviewed region and derives its color set. It
  rejects stale reviews and missing shared-color decisions instead of trusting
  a client-provided color subset.
- Original imported PNG files remain unchanged.
