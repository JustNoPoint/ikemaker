IKEMaker 0.79.440

Direct SFF, AIR, and SND additions

- The compact Add Sprites dialog now provides Add to Current SFF, which validates and writes the selected sprites directly to the currently open SFF with the IKEMaker writer.
- The compact SFF route no longer opens Advanced Creator or starts the multi-step reviewed lifecycle.
- The validated SFF write keeps an automatic backup and mutation record, clears its completed retained draft, and refreshes the current SFF viewer.
- Add Sounds now rebuilds the current SND immediately after its destination and any genuine collision choices are resolved. It no longer adds a redundant final confirmation popup.
- Creating an AIR action or adding selected sprites to an AIR action now applies directly to the current open AIR document. VS Code Undo remains available.
- Advanced, comparison, prepare-only, and specialist review routes remain available only through their explicitly named controls.
