IKEMaker 0.79.260

Text return and AIR push-box selection

- Returning from an SFF, AIR, or SND visual workspace to the connected Text Editor now validates only the originating editor group.
- Unrelated tabs and viewers in other editor groups remain open and no longer block the Text Editor route.
- Unrelated tabs that actually share the originating visual group are still protected and prevent an unsafe group close.
- The visible native Size/push box is now included in the AIR canvas right-click target list alongside overlapping Clsn1 and Clsn2 boxes.
- Selecting the Push / Size entry opens the existing explicit choice between modifying the native sizebox constant and preparing state code.
- Nested double-click selection uses stable physical box identities, so it can cycle through overlapping CLSN boxes and reach the push box even while collision ownership is loading.
- The canvas now shows the selectable hand cursor over the visible push box as well as contact boxes.

Verification

- Visual-to-text exact-group transition tests pass, including preservation of unrelated editor groups and rejection of foreign tabs in the same group.
- AIR viewer HTML and interaction-model tests pass for right-click push-box listing, explicit destination selection, cursor feedback, and nested double-click cycling.
- Text companion lifecycle and exact-source tests pass.
