IKEMEN ZSS Tools 0.79.269

Stable Slider Navigation

- The SFF sprite-position slider now previews its position while dragging and loads exactly one final sprite when released.
- Removed inherited legacy handlers from the visible SFF selector so a drag cannot trigger multiple competing selections.
- SFF onion-sprite navigation now requests only the final reference sprite.
- Pinned-source and AIR collision-frame sliders now preview cheaply and commit one final selection.
- AIR transform-angle host previews now run after the slider is released instead of requesting every intermediate angle.
- Confirmed AIR action/frame and SND archive selectors already use the same stable preview/commit behavior.
