IKEMEN ZSS Tools 0.79.267

Unified Sprite, CS, and Palette Editor

- Replaced the confusing separate Embedded Palette Inspector path with a unified Sprite, CS & Palette Editor. Bank A now clearly represents the selected embedded/source palette and Bank B is the editable comparison.
- Fixed palette colors being hidden by the universal button tint system. Palette swatches opt out of semantic button colors and paint exact RGBA values.
- Stacked Bank A above Bank B using compact fixed 16 x 16 pixel swatches instead of stretching both 256-color tables across the available panel width.
- Kept the color editor directly below the two banks with rectangular saturation/value selection, hue strip, sliders, numeric values, and exact RGBA/hex entry.
- Enlarged the image canvas into the main right-hand workspace while keeping editing controls on the left. Narrow windows place the image first and avoid overlapping controls.
- Added a browser handoff for palette, sprite, animation, and layer browsing. The browser remains the owner of lists, thumbnails, layers, and bulk selection.
- Normalized CSS alpha values in palette and sprite editing previews so transparent and partially transparent colors render correctly.
- Preserved Shift range selection, Ctrl multi-selection, A-to-B cloning, drag/copy operations, live preview, and reviewed draft adoption.
