IKEMEN ZSS Tools 0.79.237

Built-in SFF v2.1 true-color writing

- The IKEMaker SFF v2.1 writer now accepts indexed PNG8, RGB24, and RGBA32 sprites in the same archive.
- RGB24 sprites are stored as SFF v2.1 PNG24 data. RGBA32 sprites are stored as PNG32 and retain their alpha channel.
- True-color sprites require no embedded palette assignment. Indexed sprites and their palette/link behavior continue to use the existing PNG8 path unchanged.
- Exact decoded RGB/RGBA hashes, dimensions, PNG format, link compatibility, archive tables, and stored payload lengths are independently checked before a candidate is accepted.
- Runtime certification now includes deterministic RGB24, RGBA32, mixed-format, and linked true-color fixtures in addition to the existing PNG8 fixtures.
- True-color creation remains limited to SFF v2.1. SFF v1 and v2.0 continue to reject true-color input rather than silently converting it.
- Cropping true-color sprites inside this writer is not inferred; prepare a cropped source image first when cropping is required.
