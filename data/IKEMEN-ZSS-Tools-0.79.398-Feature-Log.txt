IKEMaker 0.79.398 - bounded Palette Workshop viewport updates

Removed indefinite viewport anchoring after user scrolling. Passive update
transactions retain semantic anchors for at most two seconds, and new user
input immediately cancels viewport restoration. Updates arriving during native
keyboard/wheel scrolling preserve disclosure state and document height without
replaying the gesture's starting position.

Browser regressions cover idle header shrink, expired update anchors, rapid
PageDown with repeated host messages, delayed layout, deep bank replacement,
nested disclosures, focus, and rapid update batches.

The isolated regression fails on 0.79.397. Installed/live confirmation remains
required; this release does not claim the user's remaining trigger was traced.
