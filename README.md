# IKEMaker

IKEMaker is a VS Code toolkit for creating IKEMEN GO characters and games, featuring visual editors, animation and sprite tools, searchable project data, and connected coding workflows. This repository hosts beta releases, installers, update feeds, release notes, and known issues.

IKEMaker is designed and directed by JustNoPoint (JNP), with OpenAI Codex used extensively for coding, review, testing assistance, and documentation. AI assistance does not mean every feature is verified.

## Which download should I choose?

All three downloads provide the same IKEMaker features. They differ only in how IKEMaker is installed.

- **Windows Offline ZIP — recommended if VS Code is installed:** Extract the ZIP and run the included installer. It contains IKEMaker, the official Lua Language Server, documentation, checksums, and required tools. No internet connection is needed after downloading it.
- **Windows Online Bootstrap ZIP — recommended for new users:** Use this when VS Code might not be installed. It downloads the official Microsoft-signed VS Code installer only when necessary, then installs IKEMaker and the included Lua support. If VS Code is already installed, it does not download VS Code again.
- **VSIX — advanced or manual installation:** This is the raw IKEMaker extension package. Use it for manual installation, updating an existing installation, or IKEMaker’s verified updater. VS Code must already be installed. It does not include the separate Lua Language Server package or the simplified installer.

Neither ZIP includes IKEMEN GO, MUGEN, characters, stages, game content, private workspace files, or credentials.

Download the current tester beta from the [IKEMaker releases page](https://github.com/JustNoPoint/ikemaker/releases).
