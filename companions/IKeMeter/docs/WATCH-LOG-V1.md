# IKeMeter watch log v1

Private release candidate. Meter owns capture and this contract. Maker owns source search and display. Pin 6a09392477650c527c75575a64dd728a2c200c8c. Start from standalone Meter r2, source manifest 0ae1eff34518bf8034dcd1731fbf7ac8f06ad38d7895e4a724c7b2b5e81fb26e.

## Interchange

A UTF-8 JSON object has schema "ikemeter.watch-log", numeric version 1, engineBuild (full commit string), projectId (launch manifest ID or null), sessionId (string), epoch (integer), records (ordered array). Each record has seq (strictly increasing integer within session/epoch), tick (engine GameTime), receiptMs (nonnegative integer monotonic milliseconds relative to collector epoch origin), kind, ownerId, parentId, rootId, entityId, authoredId, ordinal, generation, field, key, mapIndex, before, after, event, coverage and sourceHints. IDs, ordinals, mapIndex and generation are integers or null. A successful identity redirect supplies a runtime player ID. For a scalar ownerId is the watched character. For helper membership ownerId identifies the scanned root; parentId carries the immediate observed parent. For effects ownerId identifies the engine's selected owning character, including a root that owns a helper-created projectile. rootId is the known root runtime ID. entityId is the runtime character ID if available. An object ordinal is zero-based and valid for one observation only. Generations are optional observer counters scoped to a proven identity and continuity segment. Use null for unsupported or ambiguous identities.

kind is var, fvar, sysvar, sysfvar, map, helper, explod or projectile. field is a short string such as value, presence or count. key holds the integer watch index or normalized lowercase Map name, otherwise null. mapIndex is a separate optional signed integer (null for a plain Map). before and after are finite numbers, bounded strings, booleans or null. Null means unavailable/inapplicable; zero is a value. event is baseline, change, first, last, count or gap. first/last denote observed appearances/departures over complete scans only. count can include a baseline with before null. First after a gap is a fresh baseline. coverage is one of "complete", "partial", "unknown". Complete covers the configured watch only. Exports may include top-level retentionSeconds, dropped and truncated counters. If no watch payload fits, downstream coverage must make the missed observation visible. Finite limits apply to records, hints, strings, wire bytes, memory and per-tick work.

sourceHints is an array, empty for stock-only observation. An optional hint contains role (write/read/spawn), grade (candidate/proven), path (project-relative), sha256, line, column, endLine, endColumn (one-based, end exclusive). The hash proves the file version only. V1 defines no execution-proof artifact, so Maker treats all hints as candidates at most. A clicked change can open an explicitly chosen candidate writer, or show unknown. Reads are separate. Never infer the actual writer from one static hit, matching value, state, animation, spawn ID or tick. Maker may resolve candidates only within an explicitly mapped project and character scope, revalidate hashes, and refuse stale or ambiguous owner mappings. Existing telemetry v1 and Findings v1 stay independently usable.

## Stock availability at the pin

| Field | Stock Lua read from the existing loop hook | Semantics and gaps |
| --- | --- | --- |
| Scalar integer / float and system banks | var(i), fvar(i), sysVar(i), sysFvar(i) | Sparse nonnegative int32 indexes on selected character. Unset reads zero. No verified slot enumeration or write history. Watch explicit indexes, including high indexes. |
| Named Map | map(name), map(name,index) | Case-normalized selected-character lookup, returns number or string. An absent key and stored numeric zero look identical. A read needs a known name. No verified key enumeration. |
| Helper instance, authored ID and lineage | player(slot), helperIndexExist(n), helperIndex(n), isHelper(), id(), helperVar("id"), parent()/root() then id() | Positive helper index selects descendant in creation order. | Explod owner, authored ID and multiplicity | numExplod(), numExplod(id), explodVar(-1,n,"id") | Owner-scoped active rows, zero-based ordinal. Optional time/anim/pos x/pos y are sampled attributes. Ordinal may shift and there is no verified stable object key. |
| Active Projectile owner, authored ID and multiplicity | numProj(), numProjId(nonnegativeID), projVar(-1,n,"projid") | Active set only. Root can own a helper-spawned projectile; helperVar("ownprojectile") gives selected helper policy. Ordinal can be reused, and root ownership cannot prove creator. |

Group effects by session, epoch, owner runtime ID, kind and authored ID. Preserve simultaneous multiplicity. With two identical objects becoming one, report 2 to 1 with individual departure unknown. Even 1 to 1 cannot prove survival. Do not reuse r2's per-sample synthetic projectile numbers as lifetime IDs. Record value/type deltas only between adjacent reliable observations; same-tick A→B→A can be invisible. Repeated paused hooks add no independent tick. Reset baselines on restart, gaps and reconnect. Use bounded receipt-age retention 30–300s, default 120s, including while paused, with independent record/byte caps. Eviction cannot turn an unknown baseline into an implied zero.

### Reader bounds and project mapping

For this first cut the user explicitly selects the local character DEF to search. Display "user-selected candidate scope" even when projectId agrees. The runtime owner ID and selected DEF form no proof of execution. A future capture-time binding would need separate verified provenance. Columns are one-based UTF-16 code units and span ends are exclusive. before/after contain primitives only. Bound inputs to 8 MiB per import, 16,384 records, 16 source hints per record, 256 UTF-8 bytes per scalar string, 256 bytes per map key, and 1,024 bytes per relative path. Over-limit values yield a partial/gap observation; never silently equate a clipped value with the original. A gap row has a nonempty reason string and droppedCount (positive integer for known count, null for unknown). Receipts with partial coverage may also carry reason and droppedCount. No inference of zero loss from null. Earliest retained baseline and any retained delta carry their own meaning after age/byte eviction.

### Numeric limits and examples

seq starts at 1, epoch is nonnegative, and receiptMs, generation and all collector counters are nonnegative JavaScript safe integers. tick uses signed int32 GameTime. IDs/indexes/ordinals are nonnegative signed-int32 values or null, except mapIndex may use the full signed-int32 range. String values use the bounds above. seq order breaks receipt-time ties. Export clips by receipt age at export time including during pause. dropped and truncated, when supplied, are epoch-cumulative known rejected records and incomplete observations respectively. Count unknown upstream losses separately as unknown. Explicit loss cannot establish a departure. Use complete known baselines again after a gap.

Illustrative records below are abbreviated to highlight varying fields. Every exported record carries all common fields specified above. sourceHints defaults to [] only in the illustration.
- var: ownerId 56, rootId 56, entityId 56, key 20, field value, change 1 to 3.
- map: ownerId 56, rootId 56, entityId 56, key "watch_score", mapIndex null, field value, change 10 to 12.
- helper: ownerId 56, rootId 56, parentId 56, entityId 61, authoredId 77, field presence, first null to true.
- explod or projectile: ownerId 56, rootId 56, entityId null, authoredId 77, ordinal null, field count, count 2 to 1. Which individual went away is unknown.
- gap: preserve affected kind, use null for unknown IDs, field count or value, before/after null, event gap, coverage unknown, reason "sample-missing", droppedCount null.

Claude's targeted pre-review identified same-tick set/reset and same-tick spawn/removal as fixture cases, and recommended separating reused IDs. The stock loop cannot see intra-tick substeps or provide a birth tick for effects. Expected result for these cases is explicit sampling limits and no fabricated transitions or tombstones. Separate helper generations only when stock identity and observed continuity support them.
The retention selector offers 30, 60, 90, 120, 150, 180, 210, 240, 270 and 300 seconds. Import accepts integer metadata inside that interval.
For scope provenance a record may also carry slot (configured root slot 1 through 4) and ownerHelperId (configured nonnegative authored helper filter or null). These are watch selectors only. A failed redirect leaves observed runtime IDs unknown. Group a missing row by its selector where present, otherwise display unknown scope.
ownerHelperId, when supplied and non-null, ranges from 0 to 2147483647. The UI may further restrict ambiguous selectors. Helper-scoped effect watches use ownerId for the individual helper runtime ID and rootId for its root. An empty complete owner set differs from a failed lookup.

### Meter private candidate capture limits

Configure up to 12 watches. The Map-name field accepts 1–48 ASCII identifier characters with optional dots or hyphens after the first character. String Map values over 48 bytes are unavailable in this capture path. Indexed bank and Map watches target roots. Effects may target roots or matching helper owners. Detailed helper scanning is capped at eight enumerated helpers per root and requires a complete checked scan. Effect rows in this release carry counts. The watch section has at most 768 bytes per transport batch, fair rotation, and explicit missing-row gaps. The collector ring caps at 8,192 records and 4 MiB in addition to receipt age. Interchange limits above allow compatible readers to accept larger bounded exports.

## State-first source tracing (private state-context revision)

The optional record member stateContext carries current, previous, runStateTarget and executingEntityId. The latter two are always null for this stock capture route. current and previous are individually nullable observations {tick, entityId, stateNo, stateOwnerSlot}. stateOwnerSlot is the one-based source-table player slot observed for that state, or null. entityId identifies the sampled character. Capture pairs the current endpoint with the same tick and character as the watch observation. The previous endpoint must come from the immediately preceding observed tick of that character in the same session and epoch, without an intervening gap. It carries its own owner slot. A departure can retain a valid previous endpoint. Gap records have no usable state context. Old v1 records have no stateContext.

The stock Lua getter stateNo() exposes the selected character's active state. getStateOwnerPlayerNo() exposes that state's current source-table slot. The selected character or effect owner can be the recipient of a redirected write, rather than the actor executing a controller. Neither slot nor character ID is a source-path mapping. getStateOwnerId() also exposes the current state owner's root runtime ID, but it does not identify the writer. prevStateNo() has no paired historical owner and cannot substitute for a previous sample.

RunState is the IKEMEN state controller. Its value expression is evaluated on the caller. Redirection chooses the execution recipient, and playerno can select a different code provider. The engine executes the called bytecode and restores its temporary context. inRunState() is a boolean at query time. The stock loop has no verified getter for the called state number and its executing owner. A sampled false value cannot exclude an earlier call. See the pinned src/script.go (3967, 3981, 9075, 10496), src/bytecode.go (6332) and src/char.go (6998).

With a genuinely verified RunState target and owner, search that target first. This capture supplies no such witness. Within a correctly scoped source mapping, prefer the relevant sampled StateNo and owner, showing why it is relevant. If ownership is unresolved, the selection is only a user-selected scope. Show reachable literal calls as static possibilities; retain alternatives when endpoints cross states. Dynamic targets, custom states and redirects may require widening to prior, called, common/global and other assigned sources. Exclude read references from trace results. A selected writer or spawner can be opened for inspection; its execution remains unknown. These rules apply to the existing Var/Map/Helper/Explod/Projectile capture families.

Meter emits the full stateContext object in this revision. Sampled StateNo is signed int32. A populated stateOwnerSlot is 1 through 12 as returned by this getter on the pin. For Helper presence, the sampled entity is the child. For a count it is the observed owner. A child state or a root-owned projectile count alone cannot identify a spawning controller. Opposing endpoint evidence at the same tick breaks only that watch continuity; the next usable tick starts a fresh baseline.
The revised producer includes slot and ownerHelperId on every emitted record, including gaps. These identify the requested root and helper filter even when observed runtime ownership is unknown. Their presence is optional for reading prior v1 clips.
