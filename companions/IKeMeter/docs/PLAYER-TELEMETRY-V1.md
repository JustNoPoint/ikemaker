# Player telemetry clip v1

Meter produces explicit local UTF-8 JSON exports. Maker reads them offline. This contract covers one session, one epoch and one contiguous selection of receipt sequence numbers, including any reported gaps. Existing Findings v1 files remain separate. The fixture in `fixtures/telemetry/clip-v1.json` is synthetic interchange data.

## Envelope

The required keys are `schema` ("ikemeter.player-telemetry"), `version` (1), `session`, `retention`, `frames`, `events`, `gaps`, and `links`. All objects use the keys described here. Reject unknown versions, duplicate JSON keys, invalid types, nonfinite numbers and inconsistent references. Treat text as data. No URI or file in the clip instructs a consumer to open anything.

- `session` contains `id` (nonempty identifier, at most 160 characters), `epoch` (positive safe integer), `engineSha256` (64 lowercase hex digits), `phase` ("post-action-ui-loop"), `rootSlots` ([1,2] or [1,2,3,4]), `capabilities` and `diagnostics`. Slot order is independent of team membership. Unknown engine revisions must never inherit a verified capture capability by assumption.
- `capabilities` maps every value key in the table below to "stock", "unavailable" or "disabled". The phase and units in this contract form the epoch dictionary. The collector begins another epoch/session on a known change of observation basis or capability. Capabilities describe a read path; valid values are assessed per observation.
- `diagnostics` has string fields `stdout`, `stderr` ("owned-stream" or "unavailable") and `internalConsole` ("unavailable"). Owned streams may contain mixed-origin output. No destructive session-warning getter is drained.
- `retention` contains nonnegative safe integers `seconds`, `exportedAtMs`, `byteLimit`, `retainedBytes`, `indexBytes`, `evictedFrames`, `evictedEvents`, `droppedEvents`, `duplicateCallbacks`, and nullable `evictedThroughSeq`. `seconds` is 30 through 300 by 30 (default 120). `exportedAtMs` and every `receivedMs` are monotonic receipt times in integer milliseconds from session start. `byteLimit` is at most 67108864. `retainedBytes` includes indexes; `indexBytes` is its index component. Counts are collector totals for this epoch at export. `evictedThroughSeq` is the highest evicted frame sequence, or null. Range selection may omit earlier retained records. Age is evaluated against export time even during pause/disconnect. Clips are immutable once exported.

## Frames

A frame has `seq`, `receivedMs`, `gameTime`, `paused` (boolean or null), `roots` and `missingSlots`. Sequence starts at 1 and increases; it measures retained observations, not engine steps. GameTime is the stock nonnegative integer simulation tick. Frame sequence and GameTime are strictly increasing within the epoch, receipt time nondecreasing. Missing intermediate ticks are visible gaps. Duplicate hook callbacks can contribute heartbeat metadata without creating graph rows. A clock rewind invalidates continuity. Renderers must never connect across explicit gaps or entity generations.

Each root has integer `slot`, `teamSide` (1, 2 or null), `id` (nonnegative runtime ID), `generation` (positive collector-assigned lifetime), `validMask` (unsigned integer), `values` and `reasons`. A generation belongs to a session, epoch, slot and runtime ID. Only unique successfully redirected roots are included. `missingSlots` has one `{slot,reason}` for each omitted requested slot. Absence does not establish death. A sample cannot contain two rows for the same slot or ID.

All following keys appear in `values`, in any JSON object order. Their fixed bit positions follow the order in this table, starting at bit zero; a set bit means the value is present and valid. A missing value is JSON null, with a matching key in `reasons` and an enumerated reason. Zero, negative numeric values, and false remain valid where applicable.

| Bit(s) | Keys in order | Type when valid and meaning |
|---|---|---|
| 0–2 | posX, posY, posZ | Numeric. Camera-relative X, engine Y (+down), stage depth Z (+toward bottom bound). Raw stock units. |
| 3–5 | velX, velY, velZ | Numeric, units per simulation tick. X facing-relative; Y/Z integrate directly subject to engine movement rules. |
| 6–7 | configuredYAccel, effectiveGravity | Numeric, units/tick². First is the loaded movement.yaccel; second is unavailable on the pinned build. |
| 8–10 | stateNo, prevStateNo, anim | Signed engine integers. |
| 11 | ctrl | Boolean effective control. |
| 12–14 | moveType, stateType, physics | Stock enum strings I/A/H, or S/C/A/L/N as appropriate. |
| 15–17 | stateTime, hitPauseTime, pauseTime | Engine integer ticks. |
| 18–21 | facing, cameraPosX, localCoordX, localCoordY | Facing ±1, numeric camera X and owning-slot coordinate basis. Active-state scale can differ. |
| 22–25 | stateOwnerSlot, animOwnerSlot, spriteOwnerSlot, runOrder | Integer stock observations. Report raw slot values, including zero where the engine returns it. |
| 26–30 | spriteGroup, spriteImage, drawPalGroup, drawPalIndex, palNo | Integer stock observations. Group/image require a valid resolved sprite; selected palette and current draw palette are separate facts. |

Reasons: `unsupported`, `disabled`, `failed-read`, `failed-redirect`, `inactive`, `budget`, `unavailable`. Source, AIR, sprite and palette observations do not grant source ownership or navigation authority.

## Diagnostics, gaps and evidence

- Each event has `seq` (independent strictly increasing event receipt sequence), `receivedMs`, `source` ("stdout", "stderr" or "meter"), `origin` ("unknown", "meter", "engine" or "authored"), `severity` ("unknown", "info", "warning" or "error"), `text`, `truncated` (boolean), `originalBytes` (nonnegative integer or null), `tickDomain` ("gameTime", "tickCount" or null), `tick`, `entityId`, `stateNo` (nullable integers), and `provenance` ("owned-stream", "meter-diagnostic" or a versioned verified source parser identifier). Source order is receipt order. Only an independently verified source can assert engine/authored origin or supply scoped fields. Text alone never does. A stream name does not imply severity. There are no guessed correlations in v1. Text is capped at 4096 UTF-8 bytes at a character boundary and may contain user-local path text.
- Gaps have `receivedMs`, `kind` ("tick-gap", "discontinuity", "partial", "event-loss", "transport"), `fromTick`, `toTick`, `count` (nullable nonnegative integers) and `reason` (bounded descriptive text ≤256 characters). A gap marks missing coverage. Unknown loss count stays null. Bounded aggregates may summarize loss; counters distinguish retained eviction from upstream drops.
- A link is `{frameSeq,slot,entityId,generation,findingId,findingsSha256}`. The frame and root must exist in the clip. The sha256 identifies the complete separate Findings file. The consumer verifies its bytes and the finding's sessionId, supplied epoch, clock, tick and entity against this frame before offering the normal Findings workflow. Unknown attribution stays review-only; locators are never created from telemetry. No link is required for a clip.
- Imports are bounded to 64 MiB of UTF-8 JSON, at most 32768 frames, 2000 events, 32768 gaps, and 4096 links. A producer must report if a selection cannot fit and offer a smaller selection. It must never silently export a partial selection. Stream/export with bounded temporary memory. Retain no payload on disk automatically. Consumers must also bound parsed data and rendering work.

## Validation details

All keys enumerated above are required, except that `reasons` contains exactly the null-valued field names. No additional object keys are allowed. In addition to the retention keys above, require `truncatedEvents` (nonnegative safe integer, cumulative accepted truncated lines) and `upstreamLossUnknown` (boolean; true for unavailable upstream coverage). The collector counts accepted, truncated, evicted and quota-dropped lines independently. Neither unknown upstream loss nor an unobservable console increments a known drop count.

All integer values must be finite JS-safe integers. IDs, generation, sequence, counters, receipt times and slots have the signs and limits specified above. Stock signed integer fields fit int32; gameTime is in 0..2147483647. Numeric motion/basis fields are finite. IDs in event scopes and root IDs are in 0..2147483647. `validMask` is in 0..2147483647. Identifiers (`session.id`, `findingId`) are 1–160 characters, and versioned parser identifiers are 1–64 ASCII letters, digits, dots, underscores or hyphens. Text byte limits count UTF-8. Imported engine digest and session capabilities are producer claims; consumers may label the engine verified only against a separately known digest. Four slots designate 2v2 simultaneous play.

For every retained record, require `0 <= receivedMs <= exportedAtMs` and `exportedAtMs - receivedMs < seconds * 1000`; equality at the expiry boundary is evicted. For each of the three record arrays (frames, events, gaps), receipt times do not decrease. Gaps have both tick bounds ordered and present or both null. Event seq is independent of frame seq; absence of events during a span is legitimate. Require `0 <= indexBytes <= retainedBytes <= byteLimit`. Eviction totals describe the session; warning-loss buckets and visible gaps expire with their data. Lower configured limits can evict records earlier.

For unparsed owned output require stdout or stderr, origin/severity unknown, provenance owned-stream, null tickDomain/tick/entityId/stateNo. For Meter diagnostics require source/origin meter and provenance meter-diagnostic. Reserve explicit engine/authored provenance or severity for a recognized versioned source parser; consumers must degrade unknown parser claims to unverified data. Tick domain and tick value must both be present or both null. Do not equate tickCount and GameTime.

Existing Findings v1 can omit epoch. A producer may link a finding only when it independently verified the exact frame/root association against the immutable evidence pair, session, epoch, tick, entity and finding file digest. If v1 supplies an epoch check it, too. Without sufficient evidence emit no link. Consumers must not infer missing evidence from a coincident tick/ID. A link carries no replacement text, fix recipe or navigation authority.

The envelope additionally requires `includeDiagnostics` (boolean). Explicit clip export defaults it to false, with an empty events array. Opting in permits retained original message text, which can contain local paths. A read-only importer computes the clip digest from the imported file; it does not expect a self-hash. Any Maker association stores both the clip and Findings digests outside those immutable inputs.

Retention also includes `evictedBy` with integer counts `age`, `bytes`, `index`, `eventQuota` (whole records, all kinds). A frame batch has at most four roots and at most 32768 serialized UTF-8 bytes. Event quota is at most 100 accepted per rolling second, 2000 retained events, 8 MiB including their indexes. Aggregate warning loss summaries are bounded to 300 per-second buckets and expire. Entire batches expire at the boundary before reads or exports. No queue, index or export selection pins an expired record. Monotonic receipt age continues through disconnect and pause. On platforms where suspension breaks monotonic/wall correspondence, mark a continuity gap and conservatively expire the uncertain pre-suspend history. Local wall timestamps are never engine ticks. A new session or epoch starts fresh sequence spaces.

### Optional local stock module

JNP authorized Meter to author an optional local Lua module when the existing stock capture path cannot supply a required observation. Meter owns capture and module maintenance. First test a new module only in the isolated disposable setup using supported stock hooks. Retain a native baseline, compare match behavior with the module installed, remove it, and verify restoration. Record the engine and module hashes, observations, limitations and restoration evidence. The stock executable, real game and character files, global settings and approval controls are outside this change. Downloaded modules, binary patches, forks and publication are outside the authorization.

Internal-console access remains unverified. An owned stdout/stderr record proves receipt from that stream alone. A new module can enable an internal-console capability only after a supported read is demonstrated on the exact fixture. Existing capture can proceed independently. For stream diagnostics, originalBytes counts original line bytes. Invalid UTF-8 can decode to replacement characters, so the UTF-8 length of the exported text can differ.

### Disposable reference build

JNP permits temporary local engine instrumentation in an isolated disposable clone only when needed to validate a supported stock path. Record the reference build identity, changes, hashes and evidence separately from observations on the unmodified official Nightly. A field or warning visible only to instrumentation confers no stock capability. Sol performs final hands-on acceptance on the unmodified official Nightly. The actual Nightly and real game remain outside the experiment. Publication, maintaining a fork and bypassing an unsupported stock API are outside scope. Candidate module loading paths include external/mods or [Common] Modules with an isolated -config, and -debugdump where the build supports it. Each requires fixture verification.

The 32768-byte per-frame limit counts compact UTF-8 JSON of the stored record. The clip limit of 64 MiB applies to the actual exported or imported bytes. evictedThroughSeq is null exactly when evictedFrames equals zero. Selecting a subrange does not evict records.

Source verification on the pinned stock executable (SHA-256 73bcd922ec7e3b471a0bfc16c9d00a756e9d8abc7e0f11819a6b1bac4d63f27f) found the module loader in external/script/main.lua and loop callbacks in external/script/debug.lua. The corresponding Go system.go stores the bounded console rows and draws them internally. The inspected script.go functions clear or write console data, and the session warning getter consumes a separate value. No supported getter for retained console rows was identified in this build. This is source and file identity evidence. Native stream acceptance is tracked separately.

For newly captured linked evidence, the frozen pair verdict contains telemetryFrameSha256 only if the collector retained a paused observation at that exact GameTime when the pair was verified. It hashes the compact JSON object containing session and frame, including sequence, generation and values. The source link tool checks this digest and the retained sequence bounds before emitting a new clip. An older pair without the witness remains usable for its original Snapshot review.

A wall-clock adjustment greater than two seconds relative to the monotonic clock can invalidate retained history, as can system suspension. Event-count ceiling evictions increment evictedBy.eventQuota. Rate-limit rejections increment droppedEvents and the bounded per-second loss summary. Each loss bucket expires at the age of its first drop, so its count can leave the display up to one second before its latest drop. The cumulative droppedEvents counter remains available for the session.
