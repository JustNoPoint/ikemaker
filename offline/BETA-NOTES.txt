IKEMAKER 0.79.9 — TESTER BETA NOTES

IKEMaker is designed and directed by JustNoPoint (JNP), with OpenAI
Codex used extensively for coding, review, testing assistance, and documentation.
AI assistance does not mean every feature is verified. This file distinguishes
current work from known limits and future plans.

CURRENT HIGHLIGHTS
- 0.79.9 fixes the critical 0.79.8 AIR viewer startup regression. AIR
  animations display again, and Open SFF works with the approved green SFF
  destination color. No AIR, SFF, character, or game file migration is needed.
- Command & Movelist now preserves authored separators, whitespace, comments,
  unknown/custom parser fields, omitted defaults, neighboring definitions, and
  mixed CRLF/LF/CR line endings. Timeline and nested glyph edits change only the
  selected content; diagnostics remain advisory and do not impose an input policy.
- Move Lab now discovers exact assigned StateDefs, ZSS functions, direct HitDefs,
  Helpers, Explods, and native Projectiles. Exact source identity is revalidated
  before navigation or delegated editing, and assigned AIR actions are selected
  explicitly rather than guessed from a state or controller number.
- Direct HitDef inspection includes authored classic values and custom options,
  while the existing guarded HitDef editor remains the only mutation owner.
- Shared destination colors identify AIR, SFF, SND, code, Maps, Move Lab, stage,
  screenpack/UI, palettes, and Help routes. They can be disabled without changing
  navigation, focus behavior, or files.
- The shared Move Lab camera now keeps P1/P2 world positions stable through zoom,
  pan, resize, reset, and restoration. Exact installed interaction testing remains
  listed below; source tests do not substitute for visual confirmation.
- Lua Language Server is no longer an automatic extension dependency. Standard
  packages omit it; clearly labeled With-LuaLS variants offer it as an unchecked
  optional companion while IKEMaker's built-in Lua help remains available.
- Upgrading IKEMaker does not remove or disable a Lua extension you already
  installed. This patch does not repair Lua Language Server environment
  diagnostics; you can choose whether to keep it or disable it for this
  workspace through VS Code Extensions.
- Actual `P2, ...` redirect advice is an identified-author rule, off by default.
  It does not flag p2dist or other p2-prefixed triggers. P2's persistent opponent
  selection is contextual guidance, not an IKEMEN syntax or game rule.
- Project Maps now has visible entry points and a results-first browser with
  current-file, character, template, assigned-runtime, and combined scopes.
- AIR timeline frames can be edited directly, with missing-sprite issue navigation
  and a shared guarded Batch Apply Clsn2 workflow.
- Project-aware IKEMEN build tracking, Nightly review, backup, migration, and
  rollback tools are available for explicitly reviewed engine changes.
- IKEMaker has a separate beta updater. It checks an explicit manifest and only
  downloads or installs after the user reviews the exact release.

KNOWN LIMITS / PLANNED FIXES
- Viewer-height resizing and whole-editor vertical scrolling below every preview
  are recorded future layout requirements; they are not included in 0.79.9.
- Installed-package interaction testing remains open for the ordinary Constants
  zoom case, exact Move Lab component handoffs, AIR/Clsn workflows, shared-source
  warnings, and package-specific optional LuaLS choices.
- Help, accessibility, unusual layouts, clean-machine installation, and specialist
  editor workflows still need broader human verification.
- The online bootstrap path downloads VS Code only from Microsoft's official
  endpoint and verifies its Windows signature, but still needs wider clean-machine testing.
- This is beta software. Keep independent backups and stop if a tool selects or
  writes the wrong project, character, or file.

PLANNED — NOT YET IMPLEMENTED
- Results-first Project Data browsers for variables, functions/calls, states,
  Helpers, Explods, and projectiles.
- Additional expert-recognition workflow refinements, including searchable next-
  group choices and clearer before/after narrowing summaries in Project Maps.
- Continued installed verification and help coverage across all visual workspaces.

INSTALL / UPDATE
- Existing VS Code user: extract the Offline ZIP and run
  "Install IKEMEN Creator Tools.cmd".
- First-time user: extract the Online Bootstrap ZIP and run
  "Install IKEMaker Online.cmd". VS Code is downloaded only if absent.
- Restart or reload VS Code, then confirm IKEMaker 0.79.9.
- Future beta updates appear under IKEMaker > Personal Workspace and Preferences.
  Review the version, notes, size, and SHA-256 before choosing install.
- Downloaded update packages are retained outside game/project folders in VS Code's
  IKEMaker extension storage. The current download and one earlier cached VSIX are
  retained; this cache is not a promise of automatic rollback.

Neither package includes IKEMEN GO, MUGEN, a game, character, stage, private
workspace, or publishing credentials.
