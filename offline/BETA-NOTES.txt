IKEMaker 0.79.540

Changes since 0.79.500

- SFF and AIR viewers share layer selection and ordering. Link artwork to its base sprite, review offsets and generate attached Explod code for in-game character layers.
- Sprite intake supports uneven sheets and adjustable cuts. Use Advanced SFF for thumbnail selection, ordering and staged batches. Palette Workshop and the SFF writer include improvements to working with independent palettes.
- Command Maker opens an AIR-style compact floating Command Browser with Character Commands and Premade Commands. Coding Assistance now includes the shared toolbar.
- Command Maker names the punch mash families and adds single-kick and two-kick mash recognizers.
- Command Maker offers HDBZ-style motion recipes, optional inputs and alternative charge rules. Review CNS and ZSS output and preview the movelist with its motif styling.
- Font Lab provides font authoring alongside the screenpack, fight UI and storyboard tools.
- Screenpack previews include unnamed title and character-select backgrounds, inherited options menu text, and the correct starting roster cells. Fight HUD and storyboard previews now respect intentionally blank animation frames.

Windows downloads

New to VS Code: choose Windows Online Bootstrap.
Already have VS Code: choose Windows Offline or install the standalone VSIX through Extensions > Install from VSIX.
Choose a With-LuaLS package if you also want the Lua Language Server.
